# Add your music files here

For SONORA to play the tracks, place legally obtained audio files in this folder with these exact names:

- `01-chammak-challo.mp3`
- `02-teri-meri-kahaani.mp3`
- `03-tujhe-dekha-to.mp3`
- `04-dheere-dheere.mp3`

On macOS, run `node app.js` from the parent folder. SONORA uses the built-in `afplay` command to play the local files.
